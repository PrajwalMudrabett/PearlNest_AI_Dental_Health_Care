## 📥 How Users Can Use Your Code

### Step 1: Clone Repository

```bash
git clone https://github.com/PrajwalMudrabett/PearlNest_AI_Dental_Health_Care.git
cd PearlNest_AI_Dental_Health_Care
```

### Step 2: Install Dependencies

```bash
pip install -r requirements.txt
cd frontend
npm install
cd ..
```

### Step 3: Get Models

**Option A - Train themselves**:

```bash
python train_model1.py train
python train_model3.py train
```

**Option B - Use pre-trained weights** (if available):

- Users place weights in correct directories
- Then run: `python verify_models.py`

### Step 4: Run Application

```bash
# Terminal 1
python backend/api.py

# Terminal 2
cd frontend
npm run dev
```
